# claude-skills-marketing

Marketplace **privado** de plugins de Claude Code con skills de marketing visual de GamzyHost.
Repositorio: https://github.com/C4rI0s/claude-skills-marketing (privado: no cambiar la visibilidad).

- Cada skill tiene `SKILL.md`, plantillas con contenido real y un script de render y revisión con Chrome.
- Antes de subir un cambio en una plantilla: renderízala con su script, mira los PNG y actualiza `docs/ejemplos/`.
- Las cifras de los ejemplos se comprueban en la fuente viva (drive.gamzyhost.com, gamzyhost.com) y se fechan.
- `_ref/` (renders y recursos de trabajo) y `node_modules/` no se suben.
- Si cambias algo que el usuario tiene que recoger, sube la `version` del plugin y de `metadata.version`.
